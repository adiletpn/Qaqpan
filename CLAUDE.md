# Qalqan — контекст для Claude Code

Хакатон ITU HACKATHON-2026, FINTECH CASE (кейсодатель — Банк ЦентрКредит). Подача — 26.11.2026,
финал (офлайн, 3 мин живого демо) — 11.12.2026. Один разработчик + Claude Code.

**Продукт:** модуль защиты от мошенников внутри приложения банка. Четыре шага мошенничества —
четыре слоя: проверка сообщений (правила + Claude vision) → «Банк мне звонит?» → умный перевод
(риск, вопросы, семейный щит) → сеть защиты (жалоба одного клиента защищает всех) + помощь пострадавшему.

**ТЗ = [docs/DEMO_SCENARIO.md](docs/DEMO_SCENARIO.md).** Новые функции — только если они нужны сценарию или ответам жюри.

## Принципы (не нарушать)

1. **Один процесс, один URL, один воркер.** FastAPI раздаёт `web/dist`. Состояние демо — в памяти (`api/state.py`), без БД.
2. **Детерминизм демо.** Фиксированные ID, `POST /api/director/reset`. Фронт опрашивает API раз в ~1 с, без WebSocket.
3. **ИИ только через кэш** (`api/llm.py`, `data/llm_cache/` коммитится): кэш → живой вызов с таймаутом → фолбэк
   на правила/шаблоны. `QALQAN_DEMO=1` запрещает живые вызовы. Ни одна функция не должна падать без ключа.
4. **Тексты клиенту в платёжном потоке — только утверждённые шаблоны** (`api/texts.py`, RU/KK). Свободный текст ИИ —
   только в проверке сообщений и черновике заявления.
5. **Банковская тайна:** клиенту не показываем операции чужого счёта. Только «на этот счёт поступали жалобы».
6. **Честность:** всё замоканное (звонки банка, база АФЦ, процессинг) так и называется в README и на питче.

## Карта

```
api/        main.py (эндпоинты), state.py (данные демо), risk.py (скоринг перевода), msgcheck.py (сообщения),
            llm.py (Claude + кэш), texts.py (шаблоны RU/KK), victim.py (заявление), schemes.py (карточки схем)
web/src/    phone/ (приложение банка: BankApp, screens, overlays), pages/ (Stage, Director), api.ts, i18n.ts
scripts/    make_samples.py (скриншоты SMS), eval_messages.py (метрика), e2e_stage.py (браузерный прогон)
data/       samples.json, messages_eval.jsonl, llm_cache/
tests/      test_golden_path.py — всё демо через API
```

## Команды

```
make setup   make demo   make api   make web   make test   make eval   make samples
.venv/bin/python scripts/e2e_stage.py http://localhost:8000 /tmp/shots   # браузерный прогон со скриншотами
```
