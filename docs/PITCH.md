## Слайд 5: рынок и отличия

| Что уже есть | У кого | Чем отличается Qaqpan |
|---|---|---|
| «Доверенный контакт»: пауза, подтверждение близким, отключение за сутки | Kaspi (с 2025) | Щит срабатывает по признакам давления — звонок идёт или только что закончился, банк по своему журналу не звонит, сумма считается за весь разговор. Сын получает объяснение и ленту событий, а не «подтвердите операцию» |
| ИИ-консультант при переводе на свою карту в другом банке | рынок Казахстана (2026) | Перевод на свою карту в другом банке во время звонка — один из сигналов сессии, а не отдельная проверка |
| Защита приложения от удалённого доступа | BCC (с марта 2025) | Для нас это ещё один сигнал в риск-скор |
| «Вторая рука» — доверенное лицо подтверждает операции | Россия (с 1.09.2025) | Решение семьи и подтверждённые жалобы становятся сигналом для всех клиентов банка |

## Слайд 8: схема интеграции

Приложение банка → `сигналы сессии` (звонок, секунд после звонка, сумма новым получателям за сутки, вставка
реквизитов, переключения приложений) → антифрод BCC → `действие` (`allow` / `warn` / `questions` / `family` / `hold`)
с кодами причин → приложение показывает утверждённый текст. Подробно — [ARCHITECTURE.md](ARCHITECTURE.md#интеграция-с-антифродом-банка).
